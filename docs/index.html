Smart-Throttling Logic

Startup shouldn't take 30 minutes.

Running heavy disk tools, full scans, and package queries on every single boot ruins system performance.

Winslopr uses an intelligent persistent state file (winslopr-state.json) to monitor exactly when tasks last succeeded. If a task isn't due yet, it skips it instantly, allowing a rapid boot.

✓ Non-interactive Mode: Set it to run in Windows Task Scheduler and let it manage maintenance silently in the background.
✓ Smart Skip: Tasks like SFC / DISM run only once every 14 days by default.
✓ Bypass Switch: Force override intervals easily during active sessions using the --force or -f flags.

System Prerequisites & Dependencies

Before running Winslopr, ensure your system meets these basic requirements. Since the utility performs low-level Windows maintenance, specific components and elevated access are mandatory.

🟢

Node.js Runtime (Required)

Winslopr is built on the Node.js framework. To run the utility instantly via npx or standard scripts, you must have **Node.js v20.0.0 or higher** installed.

Download Official Installer or install instantly using your package manager:
winget install OpenJS.NodeJS
choco install nodejs
🛡️

Administrator Rights (Required)

Low-level tasks (blocking telemetry, removing system bloatware, resetting network stacks, running SFC & DISM scans) require elevated system permissions. You must open your terminal or PowerShell window **as an Administrator**.

Running the CLI in a non-admin session will trigger safety aborts or skip core repairs.

💻

Operating System Compatibility

Winslopr is custom-engineered specifically for **Windows 10 and Windows 11**. It relies directly on native Windows tools (SFC, DISM, defrag, winget) and registry modification policies that do not exist on other platforms.

--yes, -y
"Yes to All" mode. Automatically accepts all update/install checks. Skips interactive confirmation.
--silent, -s
Non-interactive mode. Skips the main selection menu, runs the default check list, and applies Smart-Throttling. Perfect for background tasks.
--force, -f
Force mode. Overrides and ignores all Smart-Throttle duration windows, forcing all active tasks to run.
--no-throttle
Disables state loading and skips writing to the local state file, running in non-throttled mode.
--info, -i
Information Mode. Instantly query and print out detailed OS, Motherboard, GPU (with VRAM), and memory diagnostics, then immediately exit.
--tasks, -t
Target specific jobs. Pass key names to run specific maintenance directly (e.g. -t sfc dns).
--config, -c
Custom Configuration. Path to a custom configuration JSON file containing custom task choices and intervals.

1. Fully Silent Maintenance (Standard Auto Run)

Runs default checks, skips prompt questions, installs necessary packages, and applies Smart-Throttling intervals.

npx winslopr -s -y

2. Forced Clean-up Override

Bypasses the throttling intervals completely and forces a deep SFC, DISM, and drive defragmentation check right now.

npx winslopr -s -y -f

3. Diagnostics-Only Mode

Exits quickly after presenting all core system information specs.

npx winslopr -i

4. Load Custom Configuration File

Runs Winslopr silently using custom task check states and throttle intervals defined in a JSON file.

npx winslopr -s -y -c "C:\path\to\config.json"

Scheduled Background Task Installation

Ensure your computer keeps running pristine clean and fully upgraded by setting up Winslopr to run silently in the background at every user login via Windows Task Scheduler (WinsloprMaintenance).

Note: Installing the scheduler requires opening your shell (PowerShell or CMD) as an Administrator.

1

Install the Task Scheduler Entry

Run the setup command from your Winslopr project directory to register the background startup task automatically:

npm run startup:install

Or invoke PowerShell directly:

powershell -ExecutionPolicy Bypass -File ./scripts/manage-startup.ps1 -Action install
2

Uninstall / Remove Automation

If you need to remove the automated startup task from Windows Task Scheduler at any time, run:

npm run startup:uninstall

Or via PowerShell:

powershell -ExecutionPolicy Bypass -File ./scripts/manage-startup.ps1 -Action uninstall

Custom Configuration JSON

Winslopr automatically scans for configuration JSON files (named winslopr.config.json, .winsloprrc.json, or .winsloprrc) in the current directory or user profile directory. You can also specify one manually using -c or --config.

Config Structure: Create a JSON file with the tasks object (booleans) and intervals object (days) as shown below.

{
  "tasks": {
    "slop": true,
    "hwInfo": true,
    "winUpdate": false,
    "winget": true,
    "choco": false,
    "dism": false,
    "sfc": false,
    "cleanup": true,
    "recyclebin": true,
    "cuttingEdge": true,
    "diskcleanup": false,
    "wucleanup": true,
    "dns": true,
    "network": false,
    "optimize": false
  },
  "intervals": {
    "cleanup": 2,
    "recyclebin": 2,
    "winget": 5,
    "choco": 5,
    "cuttingEdge": 5,
    "winUpdate": 14,
    "network": 14,
    "dism": 30,
    "sfc": 30,
    "diskcleanup": 30,
    "wucleanup": 30,
    "optimize": 30
  }
}
