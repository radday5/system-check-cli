# 🪙 qflip — Quantum Coin Flipper CLI

A simple, fun command-line tool that uses **true quantum mechanics** to flip a coin! 

Supports both **instant local simulation** (no setup needed) and **remote submission to real IBM Quantum computers** in the cloud.

---

## 🤔 What is this? (In Plain English)

On a standard computer, commands like `$RANDOM` or `random.choice()` don't generate true randomness. Instead, they use mathematical formulas (called *pseudo-random number generators*). If you know the formula and the starting seed, the output is 100% predictable.

**Quantum computers are different:**
1. We take a single quantum bit (**qubit**) and apply a quantum logic gate (the **Hadamard Gate**).
2. This puts the qubit into **quantum superposition** — a physical state where it is simultaneously **50% `0` (Tails)** and **50% `1` (Heads)** at the exact same time.
3. When the qubit is measured, quantum mechanics forces the state to collapse into either `0` or `1`.

When run on real quantum hardware, the result is generated by **fundamental laws of subatomic physics**, making it truly non-deterministic!

## ✨ Features

- **⚡ Zero Setup**: Runs instantly out-of-the-box using standard Python (no extra packages required for local mode).
- **🌐 Real Quantum Hardware**: Can submit job payloads over API to real physical quantum processors (QPUs) hosted in IBM's cloud datacenters.
- **🎨 ASCII Visualizer**: Displays a retro ASCII coin (`HEADS` or `TAILS`) for single flips.
- **📊 Batch Flips**: Supports flipping multiple quantum coins in one run to observe 50/50 statistical distributions.

## 🚀 Quick Start Guide

### 1. Instant Local Run (No API key needed)
Clone the repository and run `quantum_flip.py` with Python:

```bash
python quantum_flip.py
```

**Example Output:**

### 2. Flip Multiple Quantum Coins
Want to test quantum statistics across 10 flips? Pass the `--flips` flag:

```bash
python quantum_flip.py --flips 10
```

## 🌐 Running on Real IBM Quantum Computers

You can send your coin flip job to run on a physical quantum computer at IBM for **free**:

1. **Create a Free Account**: Sign up at [IBM Quantum Platform](https://quantum.ibm.com/).
2. **Copy Your API Token**: Find your API Token on your IBM Quantum dashboard.
3. **Install Qiskit Libraries**:
   ```bash
   pip install qiskit qiskit-ibm-runtime
   ```
4. **Run on Hardware**:
   ```bash
   python quantum_flip.py --mode ibm --token "YOUR_IBM_QUANTUM_API_TOKEN"
   ```

> **Note:** Real quantum hardware jobs are queued in IBM's cloud pipeline. The script will automatically select the least-busy quantum processor, submit your payload, and print the hardware measurement results when completed.

## ⚙️ Command Line Arguments

| Argument | Short | Description | Default |
| :--- | :--- | :--- | :--- |
| `--mode` | `-m` | Execution mode: `sim` (local simulator) or `ibm` (real quantum hardware) | `sim` |
| `--flips` | `-f` | Number of quantum coins to flip | `1` |
| `--token` | `-t` | IBM Quantum API Token (or set via `IBM_QUANTUM_TOKEN` environment variable) | `None` |

## 🛠️ SysAdmin / Technical Details

- **Quantum Circuit Architecture**:
  - **Qubit Count**: 1 qubit, 1 classical bit.
  - **Gates Applied**: `H` (Hadamard Gate).
  - **Measurement**: Measure qubit 0 into classical register bit 0.
- **Hardware Integration**: Uses IBM's `QiskitRuntimeService` and `SamplerV2` to dispatch OpenQASM circuits to available QPUs (e.g. `ibm_brisbane`, `ibm_kyiv`, `ibm_sherbrooke`).
- **Dependencies**: Python 3.8+ (standard library only for local mode; `qiskit` & `qiskit-ibm-runtime` for hardware mode).
